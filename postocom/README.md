# Poscon Frontend

React frontend for Poscon. See the [main README](../README.md) for setup instructions.

| Command         | Description                          |
| :-------------- | :----------------------------------- |
| `npm start`     | Run the app at http://localhost:3000 |
| `npm run build` | Create a production build in `build/` |
| `npm test`      | Run tests                            |
